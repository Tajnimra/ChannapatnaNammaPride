# Channapatna Namma Pride

## Project Overview
Channapatna Namma Pride is an Android application developed to promote and preserve authentic Channapatna wooden toys. It helps users explore traditional toys, learn about their craftsmanship and verify toy authenticity.

## Problem Statement
Traditional Channapatna toys need better digital visibility and authentication to help customers identify genuine products and learn about local artisans.

## Technologies Used
- Kotlin
- Android Studio
- Firebase Firestore
- Jetpack Compose
- Google Maps
- Gemini API

## Key Features
- Toy authenticity verification using a 6-digit ID.
- Artisan profiles.
- Information about how wooden toys are made.
- Educational content about Channapatna toys.
- Toy catalogue.
- Kannada and English language support.

## Future Enhancements
- Online purchasing functionality.
- More artisan profiles.
- Improved authentication features.
- Additional regional language support.
